MVP de la página web de Patojos Inmobiliaria — Captación de leads y visibilidad del inventario.


# 🏡 Patojos Inmobiliaria — MVP

## 🎯 Objetivo
Desarrollar un MVP enfocado en:
- Captación de leads.
- Visibilidad del inventario.
- Diseño Mobile First.

## 📆 Fases del Proyecto
1. Kick-Off y Diseño.
2. Desarrollo de Módulos A–E.
3. QA y Lanzamiento.

## 👥 Roles
- Programadores (Frontend / Backend)
- Diseñadores (Kit de marca)
- Mapu (Contenido y QA)

## 🛠️ Tecnologías sugeridas
- **Frontend:** React / Next.js + Tailwind CSS
- **Backend:** Node.js + Express + MongoDB
- **Despliegue:** Vercel o Netlify
